Privacy, backups & storage

Your records are saved in this browser on this iPhone. The app does not upload your financial data to a server.

iPhone web apps cannot silently write to your private iCloud Drive. Use the backup button below, then save the exported file in Files → iCloud Drive. This keeps your backup private and free, but the export step is manual.

Recommended: make a backup weekly and after important changes. Automatic background iCloud sync is not supported by this installable web app; direct iCloud integration generally requires a native iOS app or an explicitly connected sync service. Bill reminders in this version can alert while the app is open; reliable notifications when the app is closed require web push setup on a hosted site (iOS 16.4+ Home Screen app and a push server) or a native app.

About

Money MAD is an independent personal finance app. It is not affiliated with the Money Manager app. This starter version tracks finances manually and does not connect to banks or automatically pay bills.
